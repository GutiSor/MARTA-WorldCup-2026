# Data provenance

All included CSV inputs were copied without modification from `SciSynth26-main/afternoon/RWD/data/` in the user-provided archive of the ARCTIC SciSynth 2026 curriculum.

- `processed/rail_stops.csv`: instructor-prepared MARTA station coordinates.
- `processed/station_frequencies.csv`: instructor-prepared station frequency exercise input; not used to estimate actual capacity.
- `processed/ntd_marta_clean.csv`: instructor-prepared monthly NTD ridership extract.
- `processed/worldcup_reference.csv`: curriculum-provided event reference; not validated for current schedule.
- `raw/acs_b08301_fulton_dekalb.csv` and `raw/acs_b08141_fulton_dekalb.csv`: Census ACS tables, included for possible future extension; not used in current model.

Original curriculum designer: Andalib Samandari, Georgia State University ARCTIC SciSynth 2026. Original curriculum repository: https://github.com/arctic-gsu/scisynth-2026 . See `LICENSE` and the original source repository for license and source details.
